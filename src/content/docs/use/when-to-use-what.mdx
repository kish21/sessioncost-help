## The rule of thumb

- **Lines that start with `/`** go in your agent's chat. So do plain words like "fix it" and "continue from handover".
- **Lines that start with `sessioncost`** go in a terminal. You rarely need one: every row above with a `/` works in
  the chat.
- **You can ask in your own words.** "Where did the tokens go?", "fix the waste", "guard this session": your agent
  knows what to run.
