title: Install in Antigravity
description: The one-line install gives Antigravity /sessioncost and /livesession. The command-line plugin brings /sessioncost.
---
The [one-line install](/sessioncost-help/start/install/) covers Antigravity, the app and the command line, with both
`/sessioncost` and `/livesession`. That is the way to use.

**Command-line plugin:** `agy plugin install https://github.com/kish21/sessioncost`, then start a new chat. It
brings `/sessioncost` only.

After installing, restart Antigravity. You can see the guard's hooks under **Customizations → Hooks**.

**New versions:** `/sessioncost update` in a chat, or install again the same way.
