One install gives every agent on your computer both commands:

- **`/sessioncost`**: the report of where your chat's tokens went, and the fix.
- **`/liveguard`**: the guard. It is on from install in every agent; say "turn the guard off" (or type `/liveguard
  off`) to turn it off, "turn the guard on" (`/liveguard`) to bring it back.

You never have to type these: say what you want in plain words ("show my report", "fix it", "allow it"). Every
command and its words: [Commands](/sessioncost-help/reference/commands/).

## Install in one line

Nothing else needed: no Python, no Node, no Git. It fetches what it needs by itself.

1. Open a terminal. **Windows:** press the Windows key, type `powershell`, press Enter. **Mac:** Cmd + Space, type
   `terminal`, press Enter.
2. Paste the line for your computer and press Enter.

   **Windows**
   ```powershell
   irm https://raw.githubusercontent.com/kish21/sessioncost/main/install.ps1 | iex
   ```
   **Mac / Linux**
   ```sh
   curl -fsSL https://raw.githubusercontent.com/kish21/sessioncost/main/install.sh | sh
   ```
3. Wait about a minute. For each agent it finds (Claude Code, Codex, Cursor, Antigravity, GitHub Copilot in VS Code
   or its CLI) it prints `/sessioncost and /liveguard added` and `live guard ready`.
4. Restart your agents. In a chat, type **`/sessioncost`**: the report opens in your browser.

It says **no agent found**? Install your agent first (for example VS Code with GitHub Copilot), then paste the line
again. The same goes for an agent you install later.

## Other ways to install

| Way | Needs | Gives |
|---|---|---|
| [Node (npm)](/sessioncost-help/start/install/npm/) | Node.js | Every agent on the computer |
| [Python (PyPI)](/sessioncost-help/start/install/python/) | Python 3.10+ | Every agent on the computer |
| [Claude Code plugin](/sessioncost-help/start/install/claude-code/) | Git | Claude Code |
| [Codex plugin](/sessioncost-help/start/install/codex/) | Git | Codex |
| [Cursor plugin](/sessioncost-help/start/install/cursor/) | Git | Cursor |
| [Antigravity](/sessioncost-help/start/install/antigravity/) | Nothing (one line) or Git (plugin) | Antigravity |
| [GitHub Copilot](/sessioncost-help/start/install/copilot/) | The one line, Node or Python | Copilot Chat and Copilot CLI |

Use one way per agent: a plugin and the one-line install in the same agent would give it two `/sessioncost`.

## Where you type

| | **Your agent's chat** | **A terminal** |
|---|---|---|
| What it is | Where you talk to Claude Code, Codex, Cursor, Antigravity or Copilot | Your computer's command line: what you type runs exactly as typed |
| What goes there | Lines that start with `/`, such as `/sessioncost` and `/liveguard` | Lines that start with `irm`, `curl`, `npx`, `python`, `sessioncost` or `claude plugin` |

If a terminal shows an agent's chat (for example Claude Code's `>` box), type `/exit` or open a new terminal first.

## Which command to type in a terminal

The help pages write terminal commands as `sessioncost …`. Type them the way that matches how you installed:

| You installed with | The report | Any other command |
|---|---|---|
| The one line, `pipx` or `uv tool` | `sessioncost` | `sessioncost <command>` |
| Python (`pip`) | `python -m sessioncost` | `python -m sessioncost <command>` |
| Node (npm) | `npx sessioncost` | `npx sessioncost <command>` |

In a chat the commands are the same for everyone: `/sessioncost`, `/liveguard`, `/sessioncost update`.

## Stay up to date

Type `/sessioncost update` in a chat, or `update` in a terminal (`sessioncost update`, `python -m sessioncost update`
or `npx sessioncost update`). It updates every copy of SessionCost on the computer, each the right way. Then restart
your agent. Plugin users: see your agent's page above.
