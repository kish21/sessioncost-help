Prefer watching to reading? Each walkthrough below **plays by itself** in a VS Code look-alike: an agent works, and
SessionCost does its part. Nothing is installed and nothing runs on your computer. Press **Pause** any time, change
the speed, or click a step to jump to it.

## The six walkthroughs

| | Walkthrough | What you see |
|---|---|---|
| 1 | <a href="/sessioncost-help/demo/scene1.html" target="_blank">Install and update</a> | The one-line install, the Node and Python ways, each agent's own plugin, checking your copies and updating them. |
| 2 | <a href="/sessioncost-help/demo/scene2.html" target="_blank">The live guard</a> | Ordinary work goes ahead. Reading a secrets file is stopped. A web page with hidden orders for the agent is caught, and the push it asked for is blocked. |
| 3 | <a href="/sessioncost-help/demo/scene3.html" target="_blank">The guard is yours to control</a> | The guard asks about a normal step; you say "allow it". Strict, off and on, your allowed steps, and the guard report across every chat. |
| 4 | <a href="/sessioncost-help/demo/scene4.html" target="_blank">Your report</a> | "Show my report", then the path and Step 0, the charts, the agent flow, the trace and risk map, and the exports. |
| 5 | <a href="/sessioncost-help/demo/scene5.html" target="_blank">Save tokens</a> | The tip at the end of a reply, "fix it", "undo the fix", and the handover that lets a long chat start fresh. |
| 6 | <a href="/sessioncost-help/demo/scene6.html" target="_blank">Prices, older chats, clean-up</a> | The prices in use, your own and your team's prices, the list of older chats, and deleting old reports. |

They open in a new tab. Each one ends with a link to the next, and **← Help** in its top bar brings you back here.

Want to walk through a real report yourself? [Take the report tour](/sessioncost-help/report/tour/).
